02 · Build

The prototype

July–August 2026. Modelled in Fusion 360, sliced in OrcaSlicer, printed on a Creality K1C.

Components

  • Body1 m aluminium tube
  • Printed partsChamber, nose cone, box · PLA
  • SensorMAX9814 microphone
  • ControllerESP32, GPIO34, 12-bit ADC
  • Power / dataUSB
  • Parts cost1,000–1,200 ₽

Firmware

  • Window0.25 s · amplitude + RMS
  • Calibration10 s of background → RMS₀
  • EventRMS > 1.25 × RMS₀
  • Bufferlast 20 windows
  • Status0–2 Normal · 3–7 Attention · 8+ Alert

04 · Machine learning

Insect-like signal or noise?

Random Forest (scikit-learn), trained on my own recordings from the prototype.

93.4%

accuracy on held-out data, 267 of 286 windows

  • 4 classes · silence, single knocks, repeated impulses, airborne noise
  • Insect stand-in · metronome impulses, 106 / 106 correct
  • 12 features · level, spread, peaks, autocorrelation
  • Window · 20 amplitudes, step 5
  • Split · first 70% of each recording to train, last 30% to test

Confusion matrix

Rows: true class · columns: predicted
